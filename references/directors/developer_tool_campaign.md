# Developer Tool Campaign Director

Use for AI coding agents, developer tools, SaaS launch visuals, IDE-adjacent product posters, and premium technical campaign images.

Guide tone, light, material, hierarchy, and cheap/expensive cues. Do not force a command-center object, pedestal, feature-chip layout, trust strip, or official logo.

Expensive cues: real desk evidence, monitor glow interacting with objects, controlled reflections, edge rolloff, clear hero read, quiet technical atmosphere.

Cheap cues: floating UI shards, fake metrics, generic chrome orb, unmotivated neon, dense dashboard collage, invented badges.

Text policy: leave headline-safe space unless literal copy is provided. Do not invent feature labels, numbers, awards, ratings, prices, or user counts.
