# UI Marketing Mockup Director

Use for app screens, web product visuals, dashboard marketing images, and interface-as-product compositions.

Guide hierarchy, spacing, readable primary surfaces, and spatial credibility. Do not create dense fake dashboards or unreadable microcopy.

Expensive cues: stable grid, consistent spacing, readable large labels, subtle shadow depth, restrained panel count, visible interface hierarchy.

Cheap cues: misaligned widgets, nested card clutter, tiny text, fake spreadsheets, random icons, decorative glass overload.

Text policy: use short literal labels only when provided. Otherwise keep UI text abstract, sparse, and readable.
